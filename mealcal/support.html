Common questions

Where is my data stored?
In the app's local storage on your iPhone. MealCal does not upload it. You control exported files, shared copies and device backups; see the privacy policy.
How do I move my data to a new phone?
Meal Plan → More actions → Settings → Export writes a JSON backup. On the new phone, Import restores it after confirmation. Import replaces dishes, plans, templates, shopping lists and settings. Older backups without templates clear existing templates. Export a current backup first if you need to keep it.
How does the shopping list update?
Opening Shopping first generates a list for a week with meals. Later plan changes show an “Update list” notice. Updating preserves manual items. Matching checked items stay checked when quantities stay the same or decrease; increased quantities return to the to-buy list and show the old and new amount for checking. Items no longer needed are removed.
How do I reuse a week?
Meal Plan → More actions → Save as meal plan template saves dishes and diners for all seven days. Open Meal plan templates to preview and apply it. Applying replaces the target week's meals, including empty meals; occupied weeks ask for confirmation. Update the shopping list afterwards.
How do I share a plan?
Tap the share icon in Meal Plan, choose Image or Text, then share. Recipients do not need MealCal. Their replies arrive in the messaging app you chose. The shared plan is a fixed copy, so share again after edits. Shopping also supports text sharing.
Why does an ingredient say “to taste”?
Seasonings and aromatics are listed once without adding quantities across dishes. Edit any dish's ingredient amounts and base servings to match how you cook.
Are cooking instructions included?
No. The built-in dishes provide editable ingredient lists for planning and shopping, not cooking steps.
I changed the first day of the week.
Weeks are regrouped around the new start day. A plan can span two weeks, but each meal stays on its original date.
Does MealCal sync between devices?
This version does not sync. Use JSON export/import to move data. The iOS app is a one-time purchase with no subscriptions or in-app purchases.

常见问题

我的数据存在哪里？
保存在 iPhone 的 App 本地存储中，食历不会上传。导出文件、分享副本和设备备份由你自行管理，详见隐私政策。
换手机如何迁移？
周计划 → 更多操作 → 设置 → 导出数据，保存 JSON 备份；新手机导入，经确认后恢复。导入覆盖菜品、周计划、排餐模板、采购清单和设置。旧备份不含模板时会清空现有模板，如需保留当前数据请先导出。
采购清单如何更新？
有排餐的周首次进入采购页时自动生成清单。之后修改排餐会显示“更新清单”提示。更新保留手动项；匹配项用量不变或减少时继承已购状态，用量增加时恢复待买并显示新旧用量供核对。不再需要的生成项会删除。
如何复用一周菜单？
周计划 → 更多操作 → 保存为排餐模板，保存七天的菜品和人数。在排餐模板中预览并应用到目标周。应用替换整周，包括模板中的空餐；已有排餐时会要求确认。应用后请更新采购清单。
如何分享排餐？
点击周计划的分享图标，选择图片或文字，再通过系统面板发送。对方无需安装食历，修改意见在你选择的聊天工具中回复。副本不会自动更新，修改后重新分享即可。采购页也支持纯文字分享。
为什么有的食材显示“适量”？
调味料、辛香料只列一次，不把每道菜的数量累加。你可以编辑菜品的食材用量和基准人数，使其符合自己的做法。
包含做菜步骤吗？
本版提供用于排餐、采购的可编辑食材清单，不含烹饪步骤。
改了周起始日，排餐位置变了。
周的边界会重新划分，同一计划可能分到两周，但每餐仍在原本的日期。
支持多设备同步吗？
本版不支持，请用 JSON 备份迁移数据。iOS 版一次购买，无订阅、无内购。

換手機如何移轉？
週計畫 → 更多操作 → 設置 → 匯出資料，儲存 JSON 備份；新手機匯入，經確認後還原。匯入覆寫菜色、週計畫、排餐範本、採購清單和設定。舊備份不含範本時會清空現有範本，如需保留目前資料請先匯出。
採購清單如何更新？
有排餐的週首次進入採購頁時自動建立清單。之後修改排餐會顯示更新清單提示。更新保留自訂項目；相符項目用量不變或減少時保留已購狀態，用量增加時恢復待買並顯示新舊用量供核對。不再需要的產生項目會刪除。
如何重用一週菜單？
週計畫 → 更多操作 → 儲存為排餐範本，儲存七天的菜色和人數。在排餐範本中預覽並套用到目標週。套用會替換整週，包括範本中的空餐；已有排餐時會要求確認。套用後請更新採購清單。
如何分享排餐？
點選週計畫的分享圖示，選擇圖片或文字，再透過系統選單傳送。對方無須安裝食曆，修改意見在你選擇的通訊軟體中回覆。副本不會自動更新，修改後重新分享即可。採購頁也支援純文字分享。
